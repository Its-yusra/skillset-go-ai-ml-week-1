# Math for Machine Learning

## Overview

This project is part of the Skillset Go AI/ML Week 1 practical tasks.

The objective of this task is to practice the basic mathematics used in machine learning and understand how these mathematical concepts are connected to ML algorithms.

## Topics Covered

The practice includes:

* Mean
* Median
* Variance
* Standard Deviation
* Covariance
* Correlation
* Probability
* Conditional Probability
* Vectors
* Matrices
* Dot Product
* Derivatives
* Gradients
* Gradient Descent

## Work Completed

The notebook contains worked examples and solutions for the mathematical concepts.

For important formulas, the calculations are shown step by step and short explanations are included to describe what the mathematical quantities mean.

Selected concepts are also connected to machine learning applications.

## Notebook

The complete work is available in:

`Week_1_1_3_Math_for_ML.ipynb`

## ML Connections

Some of the concepts have direct connections to machine learning.

For example:

* Mean and standard deviation are useful for understanding data.
* Vectors represent features or numerical data.
* Dot products are used in weighted sums in ML models.
* Derivatives help describe how a function changes.
* Gradients are used during optimization.
* Gradient descent is used to update model parameters and reduce loss.
